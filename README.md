# Pizza App

Консольное приложение для моделирования работы пиццерии по ТЗ: заказ пиццы, информационное табло, история выданных заказов, админка, внедрение зависимостей и хранение данных в PostgreSQL.

## Что умеет приложение

- показывает меню пицц с составом, весом, калорийностью и ценой;
- оформляет заказ на одну или несколько пицц;
- считает итоговую стоимость;
- сохраняет заказы и пиццы в PostgreSQL;
- автоматически переводит заказ в статус "Готов к выдаче" через 15 минут от момента оформления с помощью фонового сервиса;
- показывает активные и готовые заказы на информационном табло;
- хранит историю выданных заказов;
- дает администратору возможность сразу выдать заказ и добавить новую пиццу.

## Архитектура

Проект разделен на простые слои:

- `Domain` - сущности и перечисления;
- `Application` - интерфейсы, DTO и бизнес-сервисы;
- `Infrastructure` - EF Core, PostgreSQL, и реализации репозиториев;
- `Presentation` - консольный интерфейс на Spectre.Console.

Используется `Microsoft.Extensions.Hosting` для DI, `EF Core` + `Npgsql` для PostgreSQL, `Spectre.Console` для аккуратного вывода и `BackgroundService` для фонового обновления статусов.

## Основные сущности

### Пицца

- идентификатор;
- название;
- описание;
- состав;
- стоимость;
- вес;
- калорийность на 100 г.

### Заказ

- внутренний идентификатор;
- номер заказа;
- статус;
- время создания;
- время готовности;
- время выдачи;
- итоговая стоимость;
- имя клиента;
- состав заказа через `OrderItem`.

## Запуск

1. Поднимите PostgreSQL локально.
2. При необходимости измените строку подключения `ConnectionStrings:Postgres`.
3. Примените миграции командой `dotnet ef database update`.
4. Запустите приложение командой `dotnet run`.

## Миграции PostgreSQL

В проект уже добавлена начальная миграция PostgreSQL.

Основные команды:

```bash
dotnet ef migrations list
dotnet ef database update
```
